# CRUDLAND: Ostatnia Baryłka

Surrealistyczne dieselpunkowe RPG 2D osadzone w świecie żywej ropy.

## Build 0.1: Platforma 17
- sterowanie WASD, strzałkami i przyciskami ekranowymi,
- rozmowa z krukiem Brentem,
- Klucz 36 i trzy baryłki do zebrania,
- misja „Czarny Poranek”,
- uruchomienie Pompy 17,
- automatyczny zapis w `localStorage`,
- responsywny interfejs na komputer i telefon.

## Lokalnie
```bash
npm install
npm run dev
```

## Publikacja
Workflow GitHub Actions publikuje zawartość `dist` w GitHub Pages po każdym commicie do `main`.
